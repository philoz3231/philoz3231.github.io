# 모바일 입력 형식

모바일에서는 긴 지시문보다 짧은 구조화 입력이 더 안정적이다. 아래 형식을 우선 사용하라.

```text
주제: 
독자: 
톤: 
길이: 

핵심 메모:
- 
- 
- 

반드시 넣을 내용:
- 

빼고 싶은 내용:
- 

이미지:
1. 파일명 또는 설명 - 이 이미지가 전달해야 할 의미
2. 파일명 또는 설명 - 이 이미지가 전달해야 할 의미
```

## 입력 해석 규칙

- `독자`가 비어 있으면 일반 독자를 기준으로 쓴다.
- `톤`이 비어 있으면 담백하고 설명적인 문체를 사용한다.
- `길이`가 비어 있으면 1200~1800자 수준의 중간 길이를 기본값으로 삼는다.
- `이미지`에는 파일 경로 대신 설명만 있어도 된다.
- 메모가 시간 순서로 보이면 후기형 구조를 우선 사용한다.
- 메모가 문제와 해결 중심이면 개발 기록형 구조를 우선 사용한다.

## 빠른 입력 예시

```text
주제: 맥북 배터리 교체 후기
독자: 교체 고민 중인 사람
톤: 솔직하고 정보성 있게

핵심 메모:
- 공식 서비스센터 예약은 쉬웠음
- 예상보다 오래 걸림
- 비용은 비쌌지만 체감 만족도 큼

이미지:
1. 수리 접수 화면 - 진행 과정 소개
2. 교체 후 배터리 정보 화면 - 결과 강조
```
