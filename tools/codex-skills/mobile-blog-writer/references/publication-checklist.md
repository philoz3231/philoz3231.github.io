# 공개 전 점검표

## 내용

- 글의 첫 3문장에서 주제와 상황이 드러나는가
- 글 전체가 하나의 주제에 집중하는가
- 각 문단이 앞뒤 문단과 자연스럽게 이어지는가
- 메모를 늘여 쓴 듯한 어색한 반복이 없는가
- 독자가 모를 배경은 최소한으로 설명했는가

## 사실성

- 사용자가 제공하지 않은 구체적 사실을 꾸며 넣지 않았는가
- 날짜, 금액, 수치가 있다면 메모에 근거가 있는가
- 타인이나 제품에 대한 단정적 평가가 과하지 않은가

## 표현

- 과장된 수식어가 과도하지 않은가
- 지나치게 광고성인 문장이 없는가
- 모바일 메모 특유의 끊긴 문장이 남아 있지 않은가
- 소제목만 읽어도 흐름이 보이는가

## 이미지

- 모든 이미지가 본문에서 역할을 가지는가
- 이미지 앞뒤 문장이 자연스럽게 연결되는가
- 이미지 설명이 파일명 수준에 머무르지 않는가

## 발행 형식

- front matter가 포함되어 있는가
- 제목, 태그, 카테고리가 비정상적으로 길지 않은가
- 본문이 마크다운으로 바로 게시 가능한 상태인가
