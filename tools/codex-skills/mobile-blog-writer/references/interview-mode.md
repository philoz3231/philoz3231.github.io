# 대화형 인터뷰 모드

모바일 사용자는 긴 템플릿 입력보다 짧은 문답에 더 잘 반응한다. 이 모드에서는 질문 수를 줄이고, 답변 부담을 낮추고, 정보가 충분해지는 즉시 초안을 작성하는 것이 핵심이다.

## 질문 순서

기본 순서는 아래와 같다.

1. 독자
2. 핵심 장면 또는 핵심 메시지
3. 이미지와 역할
4. 톤
5. 반드시 넣을 내용 또는 빼야 할 내용

`길이`는 사용자가 따로 말하지 않으면 기본값으로 추정한다.

## 질문 원칙

- 한 번에 하나만 묻는다.
- 가능한 한 한 문장으로 묻는다.
- 답변 예시를 짧게 붙여도 되지만, 선택지를 너무 많이 주지 않는다.
- 이미 확보한 정보는 다시 묻지 않는다.
- 4~6문답 안에 초안 작성을 시작한다.
- 사용자가 "알아서"라고 하면 기본값으로 바로 넘어간다.

## 질문 예시

### 시작

사용자:

```text
교토 첫날 여행 글 쓰고 싶어
```

응답:

```text
이 글은 누가 읽는 걸 상정하면 될까? 여행 준비 중인 사람, 지인 공유용, 개인 기록용 중 어느 쪽에 가까워?
```

### 핵심 장면 수집

응답:

```text
좋아. 그날 가장 강조하고 싶은 장면 2~3개만 짧게 적어줘.
```

### 이미지 수집

응답:

```text
사진 넣을 게 있으면 장면만 적어줘. 파일명 없어도 돼.
```

### 톤 조정

응답:

```text
톤은 담백한 후기, 정보성 후기, 감성 기록 중 어느 쪽에 가깝게 쓸까?
```

### 초안 전환

응답:

```text
정보가 충분해서 이제 초안으로 정리할게. Jekyll 포스트 형식으로 제목, 소제목, 이미지 배치까지 포함해 작성하겠다.
```

## 중단 조건

아래 조건 중 3개 이상을 충족하면 추가 질문 없이 초안 작성을 시작해도 된다.

- 독자가 정해졌다.
- 핵심 장면 또는 핵심 메시지 2개 이상이 확보됐다.
- 이미지 1장 이상 또는 이미지 없음이 확인됐다.
- 톤이 정해졌다.
- 반드시 넣어야 할 내용이 확인됐다.

## 후속 옵션

초안 작성 후에는 짧은 선택지만 제시하라.

- "바로 발행용으로 다듬기"
- "조금 더 짧게 줄이기"
- "제목 후보 3개 더 보기"
